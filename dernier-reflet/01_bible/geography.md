# Geography & eyelines — one axis per scene (team rule 31/10 13:40)

> « Si elle regarde derrière, la Vieille doit être derrière ; si elle regarde devant, elle doit être devant. »

Every prompt for a shot with a look, a reveal or a reverse angle **states the axis**: where the camera stands, what is behind the subject, which way the subject looks. Reverse shots swap backgrounds. Never cross the line inside a scene. Check each new still against the map below before any video.
